# 轻简 PDF 文字编辑器 · 自用

[English](README.en.md) | 简体中文

> **自用 / Personal use**：为个人日常 PDF 文字修改制作的小工具。功能保持简洁，不承诺商业支持或长期维护。

![编辑器预览](ui_preview.png)

Windows 本地中文桌面工具，支持增删文字、字体加粗、拖动定位、调整文字框及滚轮缩放。所有 PDF 内容在本机处理。

## 快速开始

1. 在 Windows 安装 Python 3.10 或以上版本，并勾选 **Add Python to PATH**。
2. 下载并解压本仓库，或使用 Git 克隆。
3. 双击 **start.bat**。首次启动会创建 `.venv` 并联网安装依赖。
4. 将 PDF 拖入窗口，完成修改后另存为新文件。

更新代码后，请关闭旧窗口并重新运行启动脚本。界面目前为中文。

## 打开文件

将一个 PDF 从资源管理器拖到编辑窗口，或者点击“打开 PDF”（Ctrl+O）。支持中文和带空格的文件路径。也可以将 PDF 拖到 start.bat 上启动并打开。请正常启动，不要以管理员身份运行，以免 Windows 阻止来自普通资源管理器的拖放。

## 添加文字

1. 选择“添加文字”，在右侧输入文字（支持多行）。
2. 选择字体、字号、颜色，可勾选“B 加粗”。提供本机已有的微软雅黑、宋体、黑体、楷体、仿宋和常用英文字体，也可选择 TTF / OTF / TTC 字体文件。
3. 在 PDF 页面上点击，放置蓝色文字框。页面显示的是 PDF 引擎的实际排版预览，尚未写入原文档。
4. 在框内按住左键拖动调整位置；拖动四角或四边中点的小方块调整文字框大小，文字会重新换行，字号不变。定位框会限制在页面内。也可点击其他位置重新定位。在页面获得焦点后，可用方向键微调 1 pt，Shift + 方向键移动 10 pt。
5. 右侧可精确设置 X、Y、宽度、高度。单位 pt（72 pt = 1 英寸）。文字超出框或字体缺字时会显示提示。较小窗口可以滚动属性面板。
6. 点击“应用文字”（Ctrl+Enter）提交，或按 Esc 取消预览。应用后仍可 Ctrl+Z 撤销。需要再次移动已应用的文字时，先撤销再重新定位。

加粗优先使用微软雅黑、Arial、Times New Roman、Consolas 对应的本机粗体文件；没有独立粗体的字体（如宋体、楷体）采用描边加粗。加粗效果会保留到导出的 PDF，不是仅在界面中显示。

字体被嵌入导出的 PDF。这里选择的是新增文字的字体，不会自动识别或匹配原文的字体。扫描件或已转为轮廓的文字无法作为文字删除；此版本不含 OCR、原文字直接改写和排版重排。

## 删除与保存

选择“框选删除”，拖动框选文字。与选框相交的字符会被真正删除，图片和线条保留。支持撤销（Ctrl+Z，最多 20 步，大文件会缩短历史）。点击“另存为”（Ctrl+S）导出新 PDF，保留原文件。

鼠标位于 PDF 编辑区时，滚轮向上放大、向下缩小，以鼠标位置为缩放中心（页面边缘受滚动范围限制）。Shift + 滚轮上下滚动页面，也可使用滚动条。右侧属性区保留原有滚动操作。缩放时复用页面排版缓存，只快速缩放当前可见区域；滚轮停止约 150 毫秒后刷新清晰图像。连续滚动期间文字可能短暂变软，导出质量不受影响。缓存仅保留当前页面的一份清晰图像。

窗口使用 Windows 原生 ttk 控件样式，支持高清屏、窗口缩放、多页浏览及“适合页面”。支持输入密码打开加密 PDF。编辑签名文件会影响其签名有效性。

## 运行与验证

需要 Python 3.10 或以上。首次启动自动安装 requirements.txt 中的依赖，后续可离线使用。PDF 内容不上传服务器。仓库不包含虚拟环境、个人 PDF 或字体文件；首次运行会自动配置环境，字体从本机读取。

- 运行：`.venv\Scripts\python.exe pdf_editor.py`
- 测试：`.venv\Scripts\python.exe -m unittest -v test_editor.py`

测试覆盖：增删文字、四种页面旋转、中文字体嵌入、带中文与空格路径的拖放回调、预览不修改文档、预览与应用的渲染一致、导出与原稿保留、撤销、八个手柄拉伸、拖动边界、滚动后的定位、鼠标锚点缩放、真实粗体与兼容加粗导出、缩放缓存复用与失效。操作系统中从资源管理器实际拖动文件的完整手势尚未自动验证。

实现依据：[PyMuPDF 页面编辑文档](https://pymupdf.readthedocs.io/en/latest/page.html)和 [TkinterDnD2](https://github.com/pmgagne/tkinterdnd2)。采用文字 redaction 删除和完整重写导出。此工具是普通编辑器，不是敏感资料清理工具（不清理元数据、附件等）。

## 项目文件

- `pdf_editor.py`：桌面编辑器。
- `start.bat`：Windows 启动脚本。
- `requirements.txt`：固定版本的依赖。
- `test_editor.py`：编辑、字体与交互回归测试。
- `README.en.md`：英文说明。
