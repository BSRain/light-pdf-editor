# 轻简 PDF v0.9.0 · Qt 版 · 自用

## 原位修改与页面旋转（v0.9.0）

- 工具选择 **修改原有文字**，点击原文字段，在预览窗口增减数字或修改同一行文字，确认后应用。清空输入会删除所选文字段，Ctrl+Z 可撤销；修改后可再次点击编辑。
- 支持可唯一复用的嵌入字体和 PDF 标准字体，保留原字号、颜色、字距、基线及加粗 / 斜体字形。新增字符若不在原字体中，或文字使用无法可靠复现的特殊排版，会提示并保留原文，不会悄悄替换字体。增长后碰到相邻文字或超出页面时拒绝应用。
- 这是单一格式文字段的编辑，不做段落自动重排；扫描图片文字需先 OCR。确认前检查实际 PDF 预览。
- 工具栏 **左转 90° / 右转 90°** 旋转当前页，可连续操作、撤销 / 重做，并保存到 PDF 或工程。先应用或取消未完成的草稿。
- 已有可编辑框随页面旋转并保留；若要用“编辑新增文字”拖动或改框，需要先旋回该框创建时的方向。包含旋转框的 `.lpdf` 工程使用格式 4，请用 v0.9.0 或更新版本打开。

## 启动

1. 安装 Python 3.10 或以上，勾选 **Add Python to PATH**。
2. 下载或克隆项目，双击 **start.bat**。
3. 首次启动会创建 `.venv` 并安装依赖；旧版用户启动时会自动补装 Qt。
4. 关闭旧窗口后重新启动。把 PDF 拖入编辑区，或点击“打开文件”。

Qt 的首次下载体积比旧版大，完成安装后可离线使用。无需管理员权限。仓库不包含个人 PDF、虚拟环境或字体文件。

## 对齐原文：推荐用法

1. 将工具切换为 **取样原文样式**，点击要参考的原文字。
2. 右侧显示检测到的字体名称、字号、颜色与粗细。对应字体在本机不可用时，会明确提示替代字体；不会伪装成完全匹配。
3. 输入要添加的文字，在目标位置点击。点击高度表示首行文字的**基线**，不再要求猜文字框顶边。
4. 靠近原文行时自动吸附到同一基线，并显示蓝色参考线；拖动也会吸附到原文左边缘或右边缘。按住 **Alt** 可临时暂停吸附。
5. 框内拖动移动，四角或四边中点拉伸；也可在右侧精确输入 X、首行基线 Y、宽度和高度。
6. 预览由 PDF 引擎生成。点击“应用文字”（Ctrl+Enter）写入文档，Esc 取消。

修改字体或字号时尽量保持首行基线不动。页面边缘会限制位置。当前只对可提取且在屏幕上水平显示的文字提供基线吸附；扫描件、轮廓文字和竖排文字不支持自动基线对齐。

小窗口下，“应用文字 / 取消预览”固定在右侧底部，属性可独立滚动。字体、字号、坐标等控件需先点击获得焦点，滚轮才会调整数值。字体列表始终提供“内置中文字体”；缺少中文系统字体时默认使用它，也可手工选择以添加中文。

## 再次编辑已添加文字

1. 应用新增文字后，选择工具栏 **编辑新增文字**，点击该文字框的位置。
2. 修改右侧文字、字体、字号、颜色或加粗；拖动文字框移动，拉动边角调整大小。
3. 预览暂时隐藏旧位置的文字，避免新旧文字叠在一起。点击 **应用修改**（Ctrl+Enter）替换，Esc 恢复原来的文字。
4. 修改作为一个完整操作支持撤销 / 重做；另存为后，不关闭当前文档仍可继续编辑。

**范围限制**：跟踪本次新增及工程恢复的文字框。重开普通 PDF 后，文字作为普通内容保留；重开 `.lpdf` 工程可恢复文字框。删除文字后，远离删除范围且不与受影响文字框重叠的新增文字框仍可编辑；相交或相互重叠的一组文字框会转为普通 PDF 文字，撤销这次删除可恢复。点击重叠文字框时，会列出文字摘要与坐标供选择，也可取消。

## 增删与保存

- 支持中英文、多行、字号、颜色、加粗和本机 TTF / OTF / TTC 字体。
- 加粗优先使用本机粗体文件；没有独立粗体时采用描边加粗。新增文字字体嵌入导出 PDF。
- **精细删除（推荐）**：单击一个字符、双击选择词段，或拖动选取中心落在框内的字符；红色高亮仅预览，点击“删除所选”或在页面按 Delete / Backspace 才执行，Esc 取消。删除前后核对未选字符的位置和内容，无法安全分离时回滚。
- **框选删除**：工具栏点击后拖动选区，松开移除相交文字字符。
- **点选删除**：工具栏点击后，将鼠标移到原文，红框预览要删除的文字段；点击删除整个文字段。更精细的局部删除请用“精细删除”。
- 删除原文可 Ctrl+Z 撤销，保留图片和线条；扫描件里的图片文字不能这样删除。
- **删除待添加文字框**：点击框使其获得焦点，再按 Delete / Backspace；只移除草稿，不改变原文。
- **重做**：Ctrl+Y 或 Ctrl+Shift+Z。撤销后执行新的编辑会清空重做分支。撤销与重做共享最多 20 步 / 128 MB 的快照预算（至少保留一个快照），大文件会缩短历史。本次会话新增的文字可用“编辑新增文字”重新修改和定位。
- “另存为”导出新 PDF，不覆盖打开的原稿。保存前需先应用或取消待编辑文字。
- 支持输入密码打开加密 PDF；加密文件撤销、导出时保留加密。

![精细删除：先预览字符选区](ui_precision.png)

精细删除按 PDF 可提取字符操作，不自动补齐删除后的空隙。完全重叠的字符需一起选择；双击按空白与标点边界选择连续词段，支持英文缩写中的撇号；中文选择连续汉字段，不做语义分词。此文字工具不处理扫描图片或文字轮廓；扫描件请使用“擦除图片区域”。

## 处理进程异常退出后

- 编辑操作会暂停，右侧输入文字仍可选中复制。
- 点击“重启处理进程”，重新打开本次最近另存的文件；没有另存记录则打开原稿，也可直接“打开文件”选择其他文件。
- **仅存在内存、没有成功恢复副本的修改不能保证恢复**。重启会询问是否放弃未保存内容，不自动声称已恢复。加密文件重新输入密码。
- 原稿不会被覆盖；若保存正在进行，重启后应检查输出文件。已启用并成功写入的恢复副本可以恢复其保存时的文档和草稿状态。

## 性能设计

- Qt 图形视图直接变换已有图像，滚轮事件不解析或重新渲染 PDF。
- PDF 打开、文字提取、编辑、预览、保存和栅格渲染均在独立进程执行。
- 停止滚动约 80 ms 后，只请求当前视口内的 512 像素图块，逐块补清晰；有低分辨率整页底图。
- 图块缓存预算 64 MiB，另有当前可见图块、整页缩略图和引擎自身内存。后台待处理视口请求只保留最新一批；过期页面结果不会覆盖当前页面。
- 重新编辑新增文字时，后台暂时持有一份文档副本，用于隐藏旧文字的底图预览；应用或取消时释放。另存为也通过副本导出，避免压缩整理影响当前会话的文字定位记录。
- 文字预览和底图分离。仅移动文字框不会重新复制整页或嵌入字体；修改文字或文字框尺寸才重新排版预览。

本机生成测试页的滚轮事件加 GUI 事件处理耗时中位数约 3.2–3.5 ms（v0.3.0 开发期间本机测量），覆盖文字、1600 条矢量线和大图背景三类页面。**这不是完整 PDF 渲染耗时，也不是所有文件的帧率保证**；不能与旧版不同测量方式的数字直接比较。可自行运行基准测试。

新增大文件操作基准，覆盖打开、图块渲染、编辑、保存、撤销 / 重做和后台峰值工作集。结果与测量限制见 [性能报告](BENCHMARKS.md)。

## 限制与自用说明

支持局部 OCR 转换和受支持字体的单段原文修改；不支持任意复杂排版改写和全篇重排。原文修改不能可靠复用字体时拒绝修改；OCR 使用替代字体，不保证原字形一致。编辑签名 PDF 会影响签名有效性。本工具不清理元数据、附件等，不是敏感资料清理工具。

本项目用于个人学习和日常自用，未附加单独的开源许可证。“自用”标注不改变 Qt、PyMuPDF 等第三方依赖和本机字体的许可条款。

实现参考：[Qt Graphics View](https://doc.qt.io/qtforpython-6.8/overviews/qtwidgets-graphicsview.html)、[PyMuPDF](https://pymupdf.readthedocs.io/en/latest/page.html)、[PyMuPDF 多进程](https://pymupdf.readthedocs.io/en/latest/recipes-multiprocessing.html)。

## v0.4.0 排版设置

- 多栏文档吸附优先选择文字框左侧定位点附近的文字行，减少远处列的干扰。
- 右侧「行距」以相邻基线之间的 PDF 点数计量；0 表示自动。取样会尝试估计同列、近似字号的相邻行，结果仍需在预览中确认。
- 选择「表格单元格填字」，点击有完整矢量边框的单元格，自动放置四周 4 pt 内边距的文字框；之后可拖动、缩放并应用文字。扫描件、缺边表格、斜线边框不支持自动识别。
- 行距随会话内文字框保留，支持重新编辑、撤销和导出。字体匹配支持导入字体的家族名称；无法匹配的窄体等字体明确回退。
- 文字框按实际行数、基线间距和字体高度检查；单行文字不会因较大行距被误判溢出。不会为适应框尺寸自动缩小字号。当前不提供段落自动重排或单元格合并操作。

## 保存可继续编辑的工程（v0.4.1）

点击「保存工程」或 Ctrl+Shift+S，另存为 `.lpdf`。工程包含当前 PDF 快照和已应用的可编辑文字框，原始 PDF 移动或删除后也能独立打开。使用「打开文件」或拖入工程，选择「编辑新增文字」继续修改。

保存前需要应用或取消预览；工程不包含撤销历史、未应用草稿和原字体文件。换电脑后可能需要重新选择本地字体。加密 PDF 的工程继续使用原密码，不在工程信息中记录密码。与 PDF 另存为一样，工程保存保留当前打开的原始文件，请选择新文件名。

「另存为」/ Ctrl+S 仍输出普通 PDF，并移除本软件的工程编辑记录；交付文件请使用这个入口。v0.4.2 可选择启用自动恢复副本，使用方法见下文。

## 自动恢复副本（v0.4.2）

1. 打开文档后，在右侧勾选「自动恢复副本」，选择本地保存目录。首次立即尝试保存，此后约每 30 秒检查一次；正在执行文件操作时顺延，内容未变化时跳过。
2. 每次启用生成一个独立的 `_恢复_日期时间_编号.lpdf`，后续原子更新这个文件。右侧显示成功保存时间和路径；每次打开文件后需重新启用。
3. 副本包含已应用的文档修改，以及页面上已放置但尚未应用的草稿，包括重新编辑中的草稿。它不会把草稿自动应用到 PDF，也不会清除未保存标记或撤销历史。
4. 异常退出后，点击「打开恢复副本」选择保存的文件。检查恢复内容，再应用 / 取消草稿并另存为 PDF 或工程。加密副本仍需原密码；密码不会记录到副本中。

恢复只能回到最近一次成功备份，之后的输入可能丢失；尚未放置到页面上的输入文字不包含在内。备份失败会暂停自动恢复并在右侧显示原因，仍可继续编辑和手动保存。关闭自动恢复或关闭软件不会删除已有副本，请自行管理保存目录和磁盘空间。恢复副本需要 v0.4.2 或更高版本。

## v0.5.0-rc.3 框内对齐与旋转选择

右侧「框内对齐」支持左对齐、居中、右对齐，每行以文字框为基准；表格填字可直接选择居中。X 始终表示文字框左侧，点击定位和拖动仍操作文字框。取样原文样式默认回到左对齐，不猜测原段落的对齐方式。

对齐设置支持预览、重新编辑、工程与自动恢复。包含新对齐设置的工程 / 恢复副本需要 v0.5.0-rc.3 或更高版本；旧版工程仍可打开。旋转页面的选择框改用精确字体度量，修正宋体等字体在 180° 页面上偏离实际文字位置的问题。

## 扫描件 / 图片局部擦除

在顶部工具下拉框选择 **擦除图片区域**，拖框选中扫描件中的内容，松开后显示红色范围预览，尚不修改 PDF。拖动框内移动、拉动边角调整大小，方向键微调（Shift 为 10 pt）；点击底部“确认擦除”或 Ctrl+Enter 后，相交图片像素清除并填入底色，同一区域的 OCR / 可提取文字也会删除。Esc / 取消预览放弃选区。Ctrl+Z 撤销，Ctrl+Y 重做；完成后“另存为”导出。无需先进行 OCR。

这不是白色覆盖框，导出会保存修改后的图片。只处理当前页，其他页面重复使用的原图仍保留；原文件、以前的导出 / 恢复副本和会话撤销记录不会自动删除。默认取选区周围的常见颜色填充，也可页面取色或手动选色；不自动修复渐变或纹理；矢量线条和批注不属于此工具的擦除范围。

确认一次后继续框选下一处，可连续擦除并逐次撤销。预览未确认时，保存和翻页会提示先确认或取消；Ctrl+Z 优先取消当前选区。自动恢复只保存已确认修改，不保存待确认擦除选区。

## 图片文字删除并填充底色

点击工具栏 **图片擦除 / 填底色**，框选图片文字。默认“自动底色”从选区周围取样；底部色值表示将填入的颜色。不准确时点击 **页面取色**，再点页面上的干净底色，或点击色值手动选色。取色完成后点击 **确认擦除 / 填底色**，最后另存为。

先删除图片中的原像素和同区 OCR 文字，再填充颜色；不是只加一个色块遮住原文。自动取色适合纯色背景，选区周边有表格线、照片或其他文字时建议手动取色。渐变、纹理不能保证无痕。原文件、历史导出和其他页复用的原图仍保留。

## 启动失败排查

便携包必须完整解压，主程序、PdfWorker.exe 和 _internal 保持在同一目录。启动器会检测常见缺失组件，并提示重新解压到新目录。可捕获的启动异常记录到 `%LOCALAPPDATA%/LightPDFEditor/logs`；目录不可写时尝试临时目录，仅保存在本机，不自动上传。日志可能包含本地路径。

启动器运行之前的系统 / Python DLL 加载失败仍可能由 Windows 或打包器直接报告。无签名程序的系统拦截不等同于程序内部错误；不要关闭系统安全设置，先核对下载来源和 SHA-256。版本验收范围见 [本机验收记录](STABILITY.md)。

## v0.6.1 故障恢复补丁

工作进程启动限时 30 秒；页面 / 分块 / 预览等请求限时 120 秒，打开、编辑、撤销、保存及恢复副本请求限时 300 秒。达到上限会停止进程并显示诊断日志位置，允许重启或打开恢复副本。繁忙时也可点击“重启处理进程”，确认后放弃未保存修改；取消则继续等待。超时不表示 PDF 已损坏，也不保证未保存操作能够恢复。保存请求可能已经写出，请另行核对输出文件。

通信单条请求 / 响应上限为 64 MiB；非法 JSON、错误请求编号和超限响应均停止当前进程，不静默跳过。该上限不是整个进程的内存上限。诊断日志在本机 `LightPDFEditor/logs` 中，以 `worker-` 开头；写入失败会在提示中说明。日志不序列化请求密码或文字正文，但 stderr 可能含本地路径或文档信息，分享前检查。

矩形删除现在和精细删除一样核对幸存字符的数量、内容和位置；无法安全保留选区外文字时回滚。最新测试数见 CHANGELOG，避免静态说明过时。

## OCR：扫描图片转为可编辑文字（v0.8.0）

1. 在工具下拉框选择 **OCR 转为文字**，框选一小块纯色背景上的横排印刷文字。识别全程离线，支持简体中文＋英文或英文。
2. 默认按行生成独立文字框。在行下拉框选择需要校对的行；位置、字号和字迹颜色自动估算，可逐行调整字体、字号、颜色及距离选区左 / 顶部的位置；底色对整个选区生效。也可切换为整块文字框。切换“原图选区 / 转换预览”比较实际 PDF 效果；放不下时减小字号或留白。
3. 点击 **确认转换（可撤销）**：清除选区内图片像素及已有文字层，填纯色，再按行写入多个可编辑文字框（整块模式仍为一个框）。任何步骤失败都整体回滚；Ctrl+Z 一次恢复原图。
4. 使用 **编辑新增文字** 点选转换后的文字框，继续改字、移动和调整；文字删除工具也可删除转换后的文字。保存 `.lpdf` 工程保留对象信息以便下次继续编辑；另存 PDF 输出真实文字。

每个识别行对应一个独立文字框，可分别修改而不移动其他行；整次选区转换仍可一次撤销。清空某行会在转换时省略该行，至少保留一行。多栏 / 多单元格仍建议分块转换。不会识别原字体、自动重建表格或复杂排版；图片内的表格线、图标、背景纹理若在选区中也会擦掉，请避开。OCR 可能有错字，必须校对。尚未转换的扫描部分仍为图片。不是仅添加隐藏搜索层。

默认目标 300 DPI，最多 1200 万像素，超大选区自动降低分辨率。识别在独立进程执行，120 秒超时，可取消；停止 OCR 不丢失 PDF 编辑会话。图像与识别结果只在内存中传递，不使用云端，不自动写入日志。周围无法取色时明确提示暂用白色，可手动选择。

便携包必须保留 `ocr_data/`，包含锁定版本的 `tessdata_fast` 简体中文 / 英文模型、SHA-256 清单和 Apache-2.0 许可证。缺失语言包仅影响 OCR。源码运行使用同目录 `ocr_data/`，无需另外安装 Tesseract 命令行程序；最终 EXE 仍需实际离线验收。

自动匹配为估算，不识别原字体；按选定替代字体的实际字迹尺寸匹配，颜色取自原图对比明显的像素。模糊、低对比或复杂背景请人工检查。 / Matching is an estimate, not original-font identification; substitute-font ink dimensions and contrasting raster colors guide placement. Inspect blurry, low-contrast or complex backgrounds manually.
